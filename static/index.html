Verification contract

✓ All routed stages exist exactly once
✓ Stage sequence obeys precedence
✓ Machines have no overlapping operations
✓ Material and order release respected
✓ Outage intervals remain unoccupied
✓ Required processing durations checked

The verifier is a separate code path, not independent of shared time and resource semantics.

Documented boundaries

○ No plant data or MES integration
○ No LLM-generated specifications
○ No parallel machines in production model
○ No labor or dynamic routing optimization
○ Search is heuristic unless a known optimum is matched

A match to a published optimum applies only to the corresponding unchanged benchmark instance.
